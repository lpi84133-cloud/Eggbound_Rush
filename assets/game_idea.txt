2. ИДЕЯ
================================================================================

Eggbound Rush — это мобильное офлайн-приложение для визуального управления
небольшим виртуальным пастбищем с курицами, гнёздами, яйцами и тематическими
объектами.

Пользователь не взаимодействует с обычным списком записей или таблицей.
Вместо этого основным рабочим пространством становится интерактивная
визуальная лужайка.

На ней пользователь размещает куриц, организует зоны, добавляет гнёзда,
отмечает яйца, фиксирует их сбор и наблюдает общее состояние пространства.

Главная особенность приложения заключается в прямом взаимодействии с
визуальными объектами. Пользователь видит схему пастбища целиком и
выполняет большинство действий непосредственно на ней.

Курицы, яйца, гнёзда, кормушки и другие объекты представлены в виде
простых тематических элементов. Их расположение позволяет быстро понять
текущее состояние пастбища без необходимости открывать большое количество
разделов.

Приложение полностью работает без подключения к интернету. Для его
использования не требуется регистрация, аккаунт, серверная инфраструктура
или внешние API.

Монетки используются как внутренний локальный показатель, открывающий
дополнительные варианты оформления и тематические объекты. Они не требуют
реальных покупок и не связаны с азартными механиками.

6. ПОЛЬЗОВАТЕЛЬСКИЙ ПРОЦЕСС
================================================================================

1. Пользователь запускает приложение.

2. При первом запуске знакомится с принципом работы.

3. Получает базовое пустое пастбище.

4. Настраивает расположение основных объектов.

5. Размещает куриц.

6. Добавляет гнёзда и другие тематические объекты.

7. Делит пространство на визуальные зоны.

8. При появлении или фиксации яйца отмечает его на пастбище.

9. После сбора обновляет локальное состояние.

10. Просматривает статистику.

11. При накоплении достаточного количества локальных монеток открывает
    дополнительные варианты оформления.

12. При следующем запуске продолжает работу с последнего сохранённого
    состояния.

7. ОСНОВНЫЕ МЕХАНИКИ ПРИЛОЖЕНИЯ
================================================================================

ВИЗУАЛЬНОЕ УПРАВЛЕНИЕ ПАСТБИЩЕМ

Главная механика приложения построена вокруг прямой работы с интерактивной
визуальной схемой.

Пользователь взаимодействует не с абстрактным списком, а непосредственно
с объектами на лужайке.

Основное состояние пастбища считывается с одного главного экрана.

-------------------------------------------------------------------------------

РАЗМЕЩЕНИЕ КУРИЦ

Пользователь выбирает курицу и размещает её на подходящем участке
пастбища.

Курицу можно перемещать между различными визуальными зонами.

Приложение сохраняет выбранное положение локально.

-------------------------------------------------------------------------------

ОРГАНИЗАЦИЯ ЗОН

Пастбище может быть разделено на функциональные участки.

Например:

• зона гнёзд;

• зона кормления;

• зона воды;

• свободная лужайка;

• зона сбора.

Каждая зона используется для более понятной визуальной организации
пространства.

-------------------------------------------------------------------------------

ОТМЕТКА ЯИЦ

Яйцо отображается как отдельный объект.

Пользователь может добавить его на схему, изменить его тип или отметить
его как собранное.

Поддерживаются:

• обычное яйцо;

• золотое яйцо;

• декоративное яйцо.

-------------------------------------------------------------------------------

ФИКСАЦИЯ СБОРА

После сбора яйца пользователь подтверждает действие.

Яйцо исчезает с активной схемы и учитывается в локальной истории.

Статистика обновляется автоматически.

-------------------------------------------------------------------------------

ЛОКАЛЬНЫЕ МОНЕТКИ

Монетки являются внутренним локальным ресурсом приложения.

Они используются для открытия дополнительных визуальных вариантов и
декоративных элементов.

Монетки:

• не приобретаются за реальные деньги;

• не являются игровой валютой;

• не используются для ставок;

• не связаны с казино;

• не используются для соревнований.

Их задача — обозначать локальный прогресс в использовании приложения.

-------------------------------------------------------------------------------

ЛОКАЛЬНАЯ СТАТИСТИКА

Приложение автоматически собирает данные о действиях пользователя.

Могут отображаться:

• количество собранных яиц;

• количество активных куриц;

• количество используемых зон;

• количество открытых декоративных объектов;

• локальный прогресс за выбранный период.

Все вычисления выполняются на устройстве.

9. СОСТОЯНИЯ И ОГРАНИЧЕНИЯ
================================================================================

Приложение не содержит условий поражения.

Пользователь может свободно возвращаться к предыдущим действиям и
продолжать работу с локальным пастбищем.

Для предотвращения перегрузки интерфейса используются следующие
ограничения:

• ограниченное количество объектов на одной визуальной зоне;

• понятное разделение крупных объектов;

• отсутствие чрезмерного количества элементов на главном экране;

• компактная статистика;

• основные действия выполняются за минимальное количество нажатий.

Если пространство становится слишком заполненным, приложение предлагает
организовать объекты по зонам, а не создавать дополнительный сложный слой
управления.

периода использования.

Более крупные темы должны требовать регулярного использования, но не
создавать ощущение искусственной блокировки.

Пользователь никогда не должен терять доступ к:

• размещению куриц;

• отметке яиц;

19. ИТОГ
================================================================================

Eggbound Rush («Яичный маршрут») — офлайн-мобильное приложение для
визуальной организации тематического пастбища с курицами, яйцами, гнёздами,
зонами и декоративными объектами.

Главная особенность приложения заключается в том, что пользователь работает
не с обычным списком или таблицей, а непосредственно с интерактивной
визуальной схемой лужайки.

Пользователь размещает куриц, организует пространство, отмечает яйца,
фиксирует их сбор и получает локальную статистику.

Монетки используются исключительно как внутренний показатель прогресса для
разблокировки косметических вариантов и не влияют на доступность основной
функциональности.

Все ключевые действия выполняются без подключения к интернету, а данные
сохраняются непосредственно на устройстве.

Сочетание простой визуальной организации, прямого взаимодействия с
объектами, понятного UX, локального хранения и яркого Premium Casual
оформления делает Eggbound Rush цельным приложением с возможностью
дальнейшего расширения без необходимости создавать сложную серверную
инфраструктуру.
